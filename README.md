# NOVA CHAT

تطبيق مراسلة عربي بواجهة سوداء وذهبية، يعمل كتطبيق ويب قابل للتثبيت على Android (PWA/Capacitor).

## الميزات الحالية
- تسجيل حساب بالبريد وكلمة المرور عبر Supabase Auth.
- البحث عن المستخدمين باسم المستخدم والمحادثات الفردية.
- رسائل نصية فورية عبر Supabase Realtime.
- إرسال الصور والرسائل الصوتية داخل المحادثات عبر Supabase Storage.
- مكالمات صوتية ومرئية عبر WebRTC مع إشارات اتصال محمية بسياسات RLS في Supabase.
- صفحة مجتمع شبيهة بإنستغرام: منشورات صور، قصص 24 ساعة، إعجابات وتعليقات.
- واجهة عربية متجاوبة وهوية سوداء وذهبية.

## النشر
- GitHub Pages workflow ينشر الموقع تلقائياً.
- GitHub Actions workflow `.github/workflows/android-apk.yml` يبني APK تجريبياً عند تحديث ملفات التطبيق أو يدوياً من Actions.
- رابط الموقع: https://alhkemeahmed34-hash.github.io/NOVE/

## إعدادات مهمة
- يجب فتح التطبيق عبر HTTPS للسماح بالكاميرا والميكروفون.
- المكالمات تستخدم WebRTC مع خوادم STUN عامة؛ بعض الشبكات/NAT قد تحتاج TURN relay لتحسين نجاح الاتصال.
- اسمح للمتصفح/التطبيق باستخدام الكاميرا والميكروفون.
- الوسائط محفوظة في حاويات Supabase خاصة، وتُنشأ روابط مؤقتة عند عرضها.
- لا تضع أبداً service_role أو secret key داخل التطبيق؛ العميل يستخدم publishable key.
- الجداول الجديدة مفعّل عليها RLS مع منح صلاحيات صريحة للمستخدمين المسجلين.
- SQL الذي يهيئ ميزات الوسائط والمكالمات والمجتمع موجود في `supabase/sql/nova_chat_features.sql`.
