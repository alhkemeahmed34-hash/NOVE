# NOVA CHAT\n\nتطبيق مراسلة عربي بواجهة سوداء وذهبية، يعمل كتطبيق ويب قابل للتثبيت على Android (PWA).\n\n## الموجود حالياً\n- تسجيل حساب بالبريد وكلمة المرور عبر Supabase Auth.\n- البحث عن المستخدمين باسم المستخدم.\n- محادثات فردية ورسائل نصية فورية عبر Supabase Realtime.\n- واجهة عربية متجاوبة للجوال والكمبيوتر.\n- دعم التثبيت كتطبيق من المتصفح بعد نشره على HTTPS.\n\n## النشر على GitHub Pages\n1. افتح Settings في المستودع.\n2. افتح Pages.\n3. من Build and deployment اختر Deploy from a branch.\n4. اختر الفرع main والمجلد /(root)، ثم Save.\n5. بعد اكتمال النشر افتح: https://alhkemeahmed34-hash.github.io/NOVE/\n\n## ملاحظات\n- قاعدة البيانات وRLS وRealtime معدّة في مشروع Supabase المرتبط.\n- لا تضع أبداً service_role key في المتصفح؛ التطبيق يستخدم publishable key فقط.\n- قد يتطلب تسجيل الحساب تأكيد البريد الإلكتروني حسب إعدادات Auth في مشروع Supabase.\n- هذا الإصدار يدعم الرسائل النصية والمحادثات الفردية؛ المكالمات والوسائط والإشعارات ليست مضافة بعد.\n
